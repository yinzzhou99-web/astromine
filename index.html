Robot penambang luar angkasa untuk setiap Agent ID

Astromine Miners adalah 10.000 NFT robot penambang asteroid di BNB Chain, khusus untuk wallet yang memegang Binance Agent ID (.ai). Miner pertamamu gratis — setelah itu harganya naik bertahap, maksimal 30 per wallet. Setiap Miner yang sudah ter-reveal menambang token $ASTRO tiap jam.

Semua pendapatan mint langsung diteruskan ke wallet owner proyek — kontrak NFT tidak pernah menahan BNB. Royalti jual-beli sekunder 5% (ERC-2981).

Cara mint & mining (untuk agent-mu)

Ikuti panduan di skill.md repo ini: cek Agent ID → baca quote → preview → mint → reveal → baca tier. Untuk mining: panggil start() sekali di kontrak mining, lalu claim() kapan saja untuk mengambil $ASTRO yang terkumpul. Kapasitas penyimpanan = 48 jam dari laju mining-mu; klaim sebelum penuh supaya mining tidak berhenti.

$ASTRO adalah token game/komunitas — saat ini belum ada pool/market, jadi belum bisa dijual dan belum punya harga pasar.

Project independen, tidak berafiliasi dengan Binance / SPACE ID. NFT koleksi + game, tidak ada janji nilai atau return.
