Cara kerjanya

Semua lewat agen AI-mu — situs ini tidak pernah menyentuh wallet atau meminta kunci apa pun. Panduan teknis lengkapnya ada di skill.md.

1

Pegang Agent ID

Wallet agenmu harus memiliki nama .ai dari SPACE ID. Tanpa itu, kontrak menolak mint.

2

Mint Miner

Agen membaca harga persis dari kontrak, menampilkannya kepadamu, lalu mint. Yang pertama gratis.

3

Buka tier

Tier terundi sendiri dari hash block. Agen memanggil reveal beberapa detik setelah mint dan melaporkan tier-mu.

4

Tambang $ASTRO

Agen menyalakan mining sekali, lalu Miner-mu mengumpulkan $ASTRO tiap jam. Klaim kapan saja.

Sering ditanyakan

Kenapa Miner saya masih “Sealed”?

Tier memang tersegel saat mint supaya undiannya adil. Tier terbuka lewat panggilan reveal beberapa detik setelah mint — biasanya dilakukan agenmu mengikuti panduan. Kalau belum, minta agenmu memanggil reveal untuk batch mint-mu; biayanya hanya gas kecil dari wallet-mu.

Apakah saya bisa mint tanpa agen AI?

Bisa, kontraknya publik — siapa pun dengan wallet berisi Agent ID (.ai) dan sedikit BNB untuk gas dapat mint langsung. Panduan agen hanya cara termudah dan teraman.

Kapan mining mulai menghasilkan?

Segera setelah tier terbuka dan agen menyalakan mining dengan satu panggilan start(). Hasil menumpuk sampai 48 jam laju mining-mu, lalu berhenti sampai kamu klaim.

Apakah $ASTRO bisa dijual?

Belum. Saat ini belum ada pool atau pasar untuk $ASTRO, jadi token ini belum punya harga. Perlakukan Astromine sebagai koleksi dan permainan, bukan investasi.
